# Практическая работа: Проект «Калькулятор»

## Функционал калькулятора:
* Базовые арифметические операции: сложение (+), вычитание (-), умножение (*) и деление (/).
* Калькулятор выполняет операцию и после этого получившийся результат становится первым операндом для новой операции.
* Наличие команд управления (C — сброс, S — выключение), которые срабатывают на любом шаге (при этом, регистр не важен):
  * ввод первого числа;
  * ввод оператора;
  * ввод второго числа.
* Защита от ошибок:
  * защита от ввода некорректных символов и случайных слов вместо чисел или операторов;
  * проверка деления на ноль с сохранением текущего результата;
  * корректное завершение работы при закрытии потока ввода (EOF).

## Алгоритм работы калькулятора:
1. Подготовка к проверке ответов пользователя при запросе числа. Калькулятор различает 4 ситуации при запросе числа:
   * получено число от пользователя;
   * вызвана команда сброса (C);
   * вызвана команда выхода (S);
   * ввод прерван.
2. Запуск калькулятора и вывод подсказки: включается считывание текста с клавиатуры, а на экране появляется приветствие
с напоминанием о командах управления (C — сброс, S — выключение).
3. Начало нового расчёта: программа запускает главный цикл работы, который позволяет начинать вычисления с чистого листа
после каждого сброса (C).
4. Запрос первого числа: калькулятор просит ввести первое число. Если ввести случайный текст вместо числа, то программа
сообщит об ошибке и попросит ввести число заново.
5. Проверка того, не вызвал ли пользователь команду (C — сброс, S — выключение) вместо первого числа: если на этом этапе
пользователь вызовет команду S, то калькулятор выключится, а если пользователь вызовет команду C, то калькулятор сбросит
ввод и снова попросит ввести первое число.
6. Запоминание первого числа: правильно введённое первое число сохраняется в памяти как текущий результат (result).
7. Программа запускает внутренний цикл, чтобы можно было выполнять сколько угодно операций подряд с текущим результатом.
8. Калькулятор просит ввести оператор (+, -, *, /) и проверяет, чтобы был введён ровно один правильный символ.
9. Проверка того, не вызвал ли пользователь управляющую команду (C — сброс, S — выключение) при выборе оператора:
если вместо оператора ввести команду C, то калькулятор сбросит текущий результат и вернётся к вводу нового первого числа,
а если ввести команду S, то калькулятор выключится.
10. Запрос второго числа: после выбора оператора калькулятор просит ввести второе число.
При этом, команды C (сброс) и S (выход) срабатывают здесь так же, как и раньше.
11. Расчет результата и защита от деления на нуль: калькулятор выполняет нужное математическое действие, а при попытке
деления на 0 выводит предупреждение и оставляет прежнее число без изменений.
12. Калькулятор выводит ответ и продолжает работу: новый результат выводится на экран, после чего калькулятор снова
предлагает выбрать математический знак для следующего действия. Результат последней операции автоматически становится
первым операндом для следующей операции.
